# Outbound ICP and launch sequence

Use this when planning Revenue Recovery Desk VSL, outreach, lead lists, or distribution. The operator gave this as context, not as a request to start outreach immediately.

## Launch order

Do **not** jump into full outreach before the system is proven. Current order:

1. Create OAuth developer accounts/apps.
2. Add app credentials locally for wired connectors.
3. Run a full end-to-end test using spare Stripe key + faux Stripe data.
4. Use Orgo's one free computer for the test; do not pay for Orgo until client money comes in.
5. Build the winning VSL script and distribution mechanism.
6. Then start targeted outreach.

## Core VSL angle

Lead with revenue recovery, not “AI agent”:

> You already did the work. The money is sitting in overdue invoices. We recover it without damaging client relationships, hiring admin, or using aggressive collections agencies.

The offer should feel like an installed Revenue Recovery Desk: overdue invoice detection, polite follow-up, dispute escalation, payment links, weekly recovered-cash reporting, and human approval/safety rails.

## Target ICPs

### Tier 1 — start here

1. **Commercial cleaning companies**
   - LinkedIn company keywords: commercial cleaning, janitorial services, office cleaning, contract cleaning, facilities cleaning
   - Best titles: Owner, Founder, Managing Director, Operations Director, Finance Manager, Accounts Manager
   - Why: recurring B2B invoices, labour costs, late client payments, payroll pressure.

2. **Security companies**
   - Keywords: security services, manned guarding, mobile patrol, event security, CCTV monitoring, corporate security
   - Titles: Owner, Managing Director, Operations Manager, Finance Manager
   - Why: payroll-heavy, contract billing, late payments hurt cash flow.

3. **Facilities management companies**
   - Keywords: facilities management, building services, property services, integrated facilities
   - Titles: Managing Director, Operations Director, Finance Director, Accounts Manager
   - Why: lots of contracts, many invoices, messy admin.

### Tier 2

4. **Commercial maintenance companies**
   - Keywords: property maintenance, building maintenance, planned maintenance, reactive maintenance
   - Titles: Owner, Managing Director, Operations Manager, Finance Manager
   - Why: job-based and recurring invoices, frequent overdue payments.

5. **Commercial HVAC companies**
   - Keywords: commercial HVAC, air conditioning services, mechanical services, heating contractor
   - Titles: Owner, Director, Operations Manager, Finance Manager
   - Why: expensive jobs, invoice disputes, delayed payments.

6. **Fire safety companies**
   - Keywords: fire safety, fire protection, fire alarms, fire suppression, fire risk assessment
   - Titles: Owner, Managing Director, Operations Director, Accounts Manager
   - Why: compliance contracts, repeat invoices, B2B client base.

### Tier 3

7. **Electrical contractors**
   - Keywords: commercial electrical, electrical contractor, building services contractor
   - Titles: Owner, Managing Director, Finance Manager, Contracts Manager
   - Why: project invoices, retentions, delayed client payments.

8. **Plumbing / mechanical / MEP contractors**
   - Keywords: commercial plumbing, mechanical contractor, MEP contractor, building services
   - Titles: Owner, Managing Director, Operations Manager, Finance Manager, Contracts Manager
   - Why: commercial projects, staged invoices, disputes, delayed payments.

## Recommended first outreach wedge

Start with **commercial cleaning + security companies**, then facilities management.

Reasons:
- easiest pain to understand;
- payroll pressure is obvious;
- recurring invoices are common;
- owners/MDs feel late payments personally;
- less complex than construction retentions/MEP disputes.

## Distribution mechanism draft

Default path:

1. Build LinkedIn lead list by company keywords + target titles.
2. Send short pain-led cold message.
3. Send VSL/landing page link.
4. Book free audit call.
5. Send payment link for setup + retainer terms.
6. After payment, send onboarding form.
7. After onboarding, send welcome pack + separate secure integration-access email.
8. Provision client profile and run readiness test.

## Outbound hook examples

Short LinkedIn opener:

> Quick question — do late-paying commercial clients ever create cash-flow pressure for your team, especially around payroll or supplier payments?

Positioning follow-up:

> We install a Revenue Recovery Desk that follows up on overdue invoices, escalates disputes, and reports recovered cash weekly — without sounding like a collections agency.

## Pitfalls

- Do not start outreach before OAuth/app setup and the full faux-data test if the user is still in build/verify mode.
- Do not over-index on “AI”; lead with cash recovery and relationship-safe collections.
- Do not position as a collections agency.
